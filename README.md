# ListenUp — TOEIC LC Lab

TOEIC LC의 문제 풀이, 즉시 피드백, 오답 복습, 받아쓰기·쉐도잉, 학습 분석을 한 흐름으로 연결한 반응형 웹 앱입니다.

## 실행

```bash
pnpm install
pnpm dev
```

Windows에서는 프로젝트 루트의 `start-listenup.cmd`를 더블클릭하면 서버와 브라우저가 함께 열립니다.

프로덕션 빌드는 `pnpm build`, 빌드 미리보기는 `pnpm preview`를 사용합니다.

## 연결된 학습 자료

- ETS Vol. 5 Test 1–10의 Part 1 사진 60장
- ETS Vol. 5 Test 1–10의 1,000문항 실제 음원 540개
- Test 1–10 공식 정답 1,000개
- Test 1의 전체 스크립트와 Test 2–10의 Part 3·4 인쇄 문항
- Test 1–10 Part 3·4 시각 자료 연계 세트 50개(표, 일정표, 지도, 웹페이지 등)

학습 설정, 최근 출제 기록, 오답 노트, 풀이 이력은 브라우저 `localStorage`에 저장됩니다. 실전 모드에서는 45분 타이머와 자동 진행을 사용하며 일시 정지·되감기·배속 조절·스크립트 표시를 제한합니다.

## 구현된 학습 기능

- TEST 1–10 세트 선택, 파트·유형·난이도·문제 수별 학습과 랜덤/기본 순서 선택
- 편향 없는 문제 셔플과 최근 60문항 우선 제외를 통한 반복 출제 방지
- 즉시 피드백/종료 후 채점, 정답 근거 구간 재생, 문장별 스크립트 재생
- 100문항 실전 모의고사, 미응답·미청취·답 변경·풀이 시간 기록
- 자동 오답 노트, 오답 원인 수정, 받아쓰기·빈칸·문장 배열·일치 문장·쉐도잉
- 파트/유형별 결과, 예상 LC 점수 범위, 누적 학습 통계

`node scripts/smoke-test.cjs`로 데스크톱·모바일 핵심 흐름을 자동 점검할 수 있습니다.
